2. Blockers — do these before buying more models

Ranked by what blocks live quality today, not the full architecture register.

IDBlockerWhy quality diesDrive this
B1 Leftover Drive downloads refill volume ENOSPC stops index, preview, backup. Manual cleanup already recovered ~41 GiB. Auto-unlink on success and ERROR. Keep uploads and YouTube. Do not buy more volume first.
B2 Overlapping video workers + 900s stall watchdog Proof video committed Media/segments then ERROR. Empty transcript, no VLM cues. One indexer replica until leases. Fencing token on finalize.
B3 Whisper / empty transcript cues Hooks must be exact transcript sentences. Empty cues make carousels unusable. Confirm faster-whisper on the indexer image. Backfill empty-cue videos. No new vendor.
B4 API and indexer share one process Search and InsightFace fight for CPU, RAM, DB pool. Carousel feels broken during video index. Split dfi-backend vs dfi-indexer (same image). Railway replica, not a SaaS.
B5 Gemini quota mixed with backfill Caption/embed 429s starve interactive generate. Weak fallbacks get cached. Pause backfill on 429. Reserve interactive quota before raising the Gemini tier.
B6 Synchronous carousel LLM stages Timeouts and retries double spend while the provider keeps running. Persist per-stage jobs + idempotency.
B7 Weak generations poison cache Cache key is provider+model+transcript, not prompt version. Bad themes stick. Claude remains script default. Force new cache id on regenerate.
B8 No search-quality regression gate eval_search_quality.py exists but is not an SLO on deploy. Run golden set after indexer deploys. Uses existing Gemini key.

Not quality blockers this quarter: Qwen GPU sidecar, Cloud Vision, SerpAPI, Cohesivity, copying /test onto /carousel.

Decision. No new SaaS vendor. Keep Claude and Gemini billed. Fund OpenRouter credits. Raise Gemini quota only after backfill is isolated. Skip GPU, Vision, SerpAPI, Apify, and Exa unless people reverse-search becomes a launch gate.

Until rungs 1–3 are green, extra model subscriptions will not show up as better carousels or better search. They will show up as more 429s and more cached junk.
