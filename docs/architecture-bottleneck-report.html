Executive summary

The binding constraint is storage lifecycle and data-plane design, not model throughput. Production has already shown a Media shadowing regression and ENOSPC. Failed work can be requeued, amplifying downloads and writes while the volume is constrained.

Critical dependency: processed Drive media is not safe to evict until video previews support end-to-end HTTP Range streaming. Today, an uncached preview is assembled in backend memory and then buffered again by the Next.js proxy.

Recommended sequence

  1. Stop disk growth and capacity-driven retry amplification; create a complete manifest.
  2. Implement and canary Range streaming through Drive, FastAPI, Next.js, and the browser.
  3. Reclaim processed Drive media, then conditionally reclaim failed Drive files after remote-access and quiescence checks.
  4. Split API and indexer into separate Railway services with shared Postgres and Qdrant.
  5. Operate against explicit storage, latency, queue, retry, and consistency targets.

Safe retention policy

KEEP

  • Upload-origin media
  • YouTube media
  • Unknown/orphan pending review
  • Any actively owned file
  • Drive SKIPPED/Media pending classification

Eligible only after Range

  • Drive PROCESSED with valid Media
  • Backend returns bounded 206
  • Next proxy streams
  • Browser seek tests pass
  • Rollback path is available

Conditional after remote-access verification and quiescence

Drive ERROR/no-Media cache may be removed only after the Drive object is proven readable, active/retry ownership is absent, the queue is paused or quiescent, and a rollback-quality manifest records identity, path, size, status, Media count, and deletion reason.

Required controls

  • Classify disk-reserve and ENOSPC failures as capacity-blocked.
  • Pause new durable cache writes and automatic retry while blocked.
  • Preserve original logical relationships until replacement commits.
  • Reconcile physical files before requeue.
  • Resume only after free-space and protected-category checks pass.

Streaming protocol checks

  • Valid single ranges return 206 Partial Content.
  • Unsatisfiable ranges return 416.
  • HEAD, MIME, length, ETag/version, and range headers are coherent.
  • Proxy preserves status and headers and streams the body.
  • Cancellation releases remote and local resources promptly.

Data-lifecycle checks

  • Dry-run and applied manifests reconcile within concurrent-write tolerances.
  • Eviction never removes Media metadata or Qdrant vectors.
  • Case-variant deduplication uses hash or stable Drive identity.

Phased remediation roadmap

Phase 0 — contain and observe

Pause capacity retries and nonessential indexing; snapshot Postgres; build manifest; protect uploads, YouTube, unknown, active, and unreviewed skipped media. Exit on stable free space and complete classification.

Phase 1 — fix media delivery

Add backend and Drive range reads; stream Next responses; test HEAD/206/416, seeking, cancellation, and memory. Canary a large video. Exit only when bounded-byte targets pass.

Phase 2 — reclaim safely

Dry-run processed Drive eviction; delete in small stoppable batches; verify seek after each batch. Handle ERROR/no-Media only after remote-read and quiescence checks.

Phase 3 — isolate API and indexing

Deploy API with RUN_INDEXER=false and one indexer replica with RUN_INDEXER=true. Verify leader ownership, shared stores, independent restarts, and API SLOs under load.

Phase 4 — harden lifecycle

Add high/low watermarks, persisted retry scheduling, resource circuits, daily reconciliation, idempotent carousel jobs, and restore/outage/full-volume exercises.

Potential ceiling, not a promise: Drive ERROR + Drive PROCESSED categories total 77.848 GiB. Actual reclaim must subtract protected, active, non-reproducible, and verification-failed files.

Decision log

  • Do not delete processed Drive cache before Range streaming.
  • Keep upload, YouTube, unknown, active, and pending-review media.
  • Treat failed Drive cleanup as conditional.
  • Do not add duplicate-case bytes to category totals.
  • Do not represent local safeguards as deployed.
  • Start with one indexer replica.
